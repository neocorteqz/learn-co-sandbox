# AI Agent Guidelines for learn-co-sandbox

## Project Overview

This is a **Learn.co Sandbox** repository—a personal learning environment for practicing code from lessons, "readme" lessons, and "code-along" exercises on the Learn platform.

**Important**: This repository is auto-synced to GitHub and should NOT be edited directly on GitHub. Work only in the IDE Sandbox.

## Workspace Purpose

- Practice coding exercises and lessons
- Experiment with different programming concepts
- Test code before moving to actual lab projects
- Build up a portfolio of learning examples

## How to Help

When assisting with code in this sandbox:

1. **Provide clear explanations** alongside code examples—learning is the goal
2. **Comment your code** to help reinforce concepts
3. **Suggest best practices** but prioritize clarity and understanding over production optimization
4. **Point to resources** (documentation, tutorials) when explaining new concepts
5. **Test code thoroughly** before suggesting solutions

## Supported Languages & Technologies

### PHP
- Server-side scripting and backend logic
- Focus on fundamentals: variables, functions, control structures, arrays
- Best practices: proper error handling, input validation, security basics (SQL injection prevention)
- Comment code to explain server-side processes and database interactions

### HTML & CSS
- Frontend markup and styling
- HTML: semantic structure, accessibility, form handling
- CSS: layout techniques (flexbox, grid), responsive design, styling best practices
- Emphasize clean, semantic HTML and maintainable CSS

### MySQL
- Relational database design and SQL queries
- Cover: CREATE/INSERT/SELECT/UPDATE/DELETE operations, JOINs, WHERE clauses
- Database design principles: tables, primary keys, foreign keys, normalization
- Always highlight SQL best practices and security (parameterized queries)

### Full-Stack Integration
- PHP handling form submissions from HTML
- PHP connecting to MySQL for data persistence
- CSS styling complete web applications
- Explain how layers interact (frontend → backend → database)

### Windows Application Building
- C# and .NET fundamentals for desktop applications
- WinForms and WPF for building Windows user interfaces
- Event handling, controls, and UI layout
- Best practices: proper resource management, exception handling, user experience design
- Explain how Windows application architecture differs from web applications
- Comment code to clarify UI event flows and component interactions

## Common Patterns

- Single-file exercises (often focused on one concept)
- Python, JavaScript, PHP, C#, HTML, CSS, or other language fundamentals practice
- Windows desktop application projects using C# and .NET
- Database exercises with MySQL schema and queries
- Full-stack mini-projects combining multiple technologies
- Incremental learning—exercises build on previous lessons
- Experimentation is encouraged—try variations of suggested solutions

## Getting Help

To get the most out of AI assistance:
- Describe what you're trying to learn or understand
- Include any error messages or unexpected behavior
- Ask for explanations, not just solutions
- Request alternative approaches to deepen understanding
